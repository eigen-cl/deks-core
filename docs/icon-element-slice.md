# Native icon element — next vertical slice

The design catalog now supplies trusted offline path geometry. The next slice must add a native
element instead of storing arbitrary SVG or converting icons to raster assets.

## Portable document contract

```ts
interface IconElementState extends BaseElementState {
  kind: "icon";
  icon: { family: "lucide"; name: string };
  color: string;       // #RRGGBB
  strokeWidth: number; // 0.5..8 in the family's 24-unit viewBox
}
```

`family + name` are stable catalog keys. A `.deks` document never stores a URL, SVG markup, script,
font glyph or implementation-specific React component. Import validates that the family is registered
and the name exists. Missing future families fail closed instead of making a network request.

## Relational Cloud contract

- Extend `elements.kind` with `icon`.
- Add joined subtype `icon_element_states`, keyed by `id` with
  `FOREIGN KEY (id) REFERENCES element_states(id) ON DELETE CASCADE`.
- Columns: `family VARCHAR(32) NOT NULL`, `icon_name VARCHAR(100) NOT NULL`,
  `color VARCHAR(7) NOT NULL`, `stroke_width FLOAT NOT NULL`.
- Checks: `family IN ('lucide')`, `color ~ '^#[0-9A-F]{6}$'`, and
  `stroke_width >= 0.5 AND stroke_width <= 8`.
- Do not add JSON/JSONB or an SVG blob column. The subtype participates in clone, add-existing,
  undo/redo, import/export and the same `create_element` / `update_element_state` commands.

REST and MCP add these replaceable state fields to the existing command:

```text
kind="icon"
icon_family="lucide"
icon_name="shield-check"
color="#5EEAD4"
stroke_width=2
```

## Renderer contract

`ElementSnapshot` gains `{ kind: "icon", family, iconName, color, strokeWidth }`. The imperative
renderer creates one SVG in the element rectangle, sets the catalog `viewBox`, `fill`, linecap and
linejoin, and appends only `<path d>` values looked up in its bundled catalog. It never assigns
`innerHTML` and never accepts path data from a presentation document.

Geometry, rotation, opacity and color animate like existing elements. When the stable identity keeps
the same `family + iconName`, normal interpolation applies. A glyph change is a discrete cut at the
transition midpoint (or an immediate cut under reduced motion); path morphing is out of scope.

PPTX export converts the trusted catalog entry to an SVG data URI generated by the exporter itself.
The editor picker groups by family and semantic tags; Lucide is first, while Font Awesome and
Material/MUI become additional registered adapters with their own bundled geometry and license
metadata. Adding a family must not change the document or renderer contract.
